# UFO Map — уфологічна мапа

Карта точок аномальної енергії, НЛО-спостережень і місць сили (Україна, Нідерланди) у стилі DeepStateMap.
Статичний сайт: Vite + TypeScript + MapLibre GL JS, хостинг на GitHub Pages.

- Почати: [`START_HERE.md`](START_HERE.md)
- План: [`docs/PLAN.md`](docs/PLAN.md)
- Промпти для Claude Code: [`docs/PROMPTS.md`](docs/PROMPTS.md)
- Дані: [`data/points/`](data/points/) · схема: [`schema/point.schema.json`](schema/point.schema.json)

> Карта збирає повідомлення уфологів, езотериків і очевидців. Вони не є науково підтвердженими фактами.
> Не відвідуйте приватні, закриті чи небезпечні території.
