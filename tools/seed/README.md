# Стартові дані

`build_seed.py` — Python-скрипт, з якого зібрано `data/points/ua.geojson`, `nl.geojson`,
`public/data/all.geojson` і `preview.html` (21.11.2026).

Запуск: `python3 tools/seed/build_seed.py` (потрібен лише Python 3).

Увага: після того як ви почнете редагувати `data/points/*.geojson` напряму або через Claude Code,
цей скрипт більше не запускайте — він перезапише файли стартовими даними.
